# Emberfall — Game Vision

## Genre

Narrative pixel art RPG with exploration, choices and turn-based combat.

## Core Experience

The player travels through a fantasy world following interconnected
paths, discovering locations, characters, enemies and narrative events.

Choices made during exploration can affect future events.

## Core Pillars

- Exploration
- Meaningful Choices
- Character Progression
- Turn-Based Combat
- Discovery

## Visual Style

Modern pixel art inspired by classic 1990s RPGs.

## Platform

Web Browser.

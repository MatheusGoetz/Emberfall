# Emberfall

Emberfall is a browser-based pixel art RPG focused on exploration,
choices, turn-based combat and character progression.

The project is also a game engineering learning environment combining
web development, game development and software engineering.

## Architecture

### Web Client
- React
- TypeScript
- Vite

### Game Runtime
- Phaser

### Game Core
- C++
- WebAssembly
- Emscripten

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA

### Database
- PostgreSQL

### Infrastructure
- Docker
- Docker Compose
- GitHub Actions

## Project Goals

The project is designed to practice:

- Web development
- Game development
- Programming logic
- Software architecture
- Git and version control
- Automated testing
- CI/CD
- Deployment

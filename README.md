# Emberfall

Emberfall is a browser-based pixel art RPG focused on exploration,
choices, turn-based combat and character progression.

The project is also a game engineering learning environment combining
web development, game development and software engineering.

## Planned Stack

### Game Client
- React
- TypeScript
- Phaser

### Backend
- C#
- ASP.NET Core
- PostgreSQL

### Game Engine Modules
- C++
- WebAssembly

### DevOps
- Git
- GitHub
- GitHub Actions
- CI/CD
